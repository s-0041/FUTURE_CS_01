# FUTURE_CS_01 — Vulnerability Assessment

## Website Tested
Castorama France
https://www.castorama.fr/

## Scope
A read-only security assessment was performed against the publicly accessible website.

The assessment focused on:
- HTTPS/TLS configuration
- HTTP security headers
- Cookie security attributes
- Client-side security observations
- Network/request behaviour

## Tools Used
- Chrome DevTools
- OWASP ZAP
